## ⚠️ THE DAY 6 TRAP — read once, then never again

The trap is **THE PRIVATE MUTATION.**

You will do real work today — and try to keep it invisible. Write the offer, not publish it. Draft the message, not send it. Build the thing, not announce it. Unseen changes can't be judged, so they can't fail — and so they aren't evidence. **If no one could dispute your evidence, it is not evidence yet.**

Second head: **THE WORTHINESS DELAY.** "It needs to be better before anyone sees it." The mutation doesn't need to be impressive. It needs to be *real* — a state change the world can check. The send button is the mutation. Everything before the send is rehearsal, and rehearsal is Day 1–5 work. That budget is spent.

The selection tell, this morning: you will feel pulled toward the candidate that is quietly reversible. The Gate asks "why is it hard to reverse" precisely to catch that pull at selection time, not at midnight.
